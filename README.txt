PUBBLICAZIONE GITHUB PAGES:
1. Estrai questo ZIP.
2. Carica index.html, style.css, script.js e la cartella assets nel repository astromarcoo.github.io.
3. Vai in Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main / (root).
6. Save.
